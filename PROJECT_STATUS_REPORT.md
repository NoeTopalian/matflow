## 1. Executive summary

MatFlow is a multi-tenant SaaS for martial-arts gyms: staff dashboard (members, timetable, attendance, billing, reports), a member portal, a kiosk/QR check-in surface, a public TV leaderboard, and an operator plane for the platform owner. Stack: Next.js 16 (App Router, Turbopack), React 19, TypeScript, Tailwind v4, Prisma 7 on Neon Postgres with row-level security, NextAuth v5, Stripe Connect (each gym is merchant of record), Resend email, Vercel Blob, Vercel Cron.

**Maturity (evidence-based):** a single-tenant pilot is the declared goal — one paying gym (Total BJJ, owner Sean), sold concierge-style; the code is built for many tenants and its isolation has been adversarially tested. The application has a large automated net: 2,072 unit/integration tests (0 failing), a 24-file end-to-end "assess" suite that reached 579 passed / 0 failed (10 skipped) on three full serial runs this week, and, today, seven independent assessment lanes on the Reports surface with every HIGH finding fixed and re-verified. Whether the **critical workflows are verified** is answered per workflow in §4 with the verification level actually reached — several are verified end-to-end only on the isolated test database, not on production, and some depend on production configuration that is **not set**.
