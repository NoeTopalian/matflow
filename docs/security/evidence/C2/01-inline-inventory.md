Decision: script-src = `'self' 'nonce-…' 'strict-dynamic'` + the two legacy hosts (CSP2 fallback only), no `'unsafe-inline'`; style-src = `'self' 'unsafe-inline' https://fonts.googleapis.com` (residual: CSS injection is not closed — it is not script execution, and every dynamic style value found is constrained, above).

## Pages outside the proxy before this change
`/kiosk/*` and `/leaderboard/*` were excluded by the `proxy.ts` matcher, so they could never receive a per-request nonce. They now enter the proxy, which sends them the policy and skips the next-auth wrapper (`isTokenDocumentPath`, `lib/csp.ts`). `/api/kiosk/*` stays excluded. All `/api/*` responses get no document policy (JSON/CSV/bytes); the static `next.config.ts` policy still applies to every response.
